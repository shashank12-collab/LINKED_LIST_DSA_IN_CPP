# Linked List in C++  

A collection of C++ implementations of different types of linked lists — singly, doubly, circular — along with common operations (insertion, deletion, reversal etc.).  

## 🚀 Project Overview  

This repository contains multiple linked-list implementations in C++, covering:  
- Singly Linked List  
- Doubly Linked List  
- Circular Linked List  
- Common operations: insertion (head, tail, at position), deletion (by value, by position, head/tail), reversal, flattening (for doubly/circular if applicable), finding middle or loops, merging sorted lists, checking palindrome, sorting, intersection detection, addition of two lists, and many other variations.  

It’s intended as a learning and practice resource for Data Structures & Algorithms (DSA) — especially helpful for beginners and for preparing for coding interviews or assignments.  

## 📂 Contents / Topics Covered  

- Singly Linked List  
- Doubly Linked List  
- Circular Linked List  
- Insertion (head, tail, at-position / by value)  
- Deletion (head, tail, by index, by value, deleting duplicates, delete middle, delete occurrences, etc.)  
- Reversal (singly / doubly / circular)  
- Sorting a linked list, Sort 0-1-2 type linked list  
- Merging sorted linked lists  
- Finding intersection / Y-intersection in two lists  
- Adding two linked lists (as numbers)  
- Converting arrays to linked list / DLL and vice versa  
- Detecting loops, finding middle node, removing loops  
- Checking palindrome linked list  
- Flattening, copying, merging lists, rotating by k, reverse in groups / reverse singly list, etc.
